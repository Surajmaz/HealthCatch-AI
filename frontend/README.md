# HealthCatch AI — Frontend

This is the frontend (React + Vite) half of the HealthCatch AI project.

**For full setup instructions (backend, Firebase, environment variables,
troubleshooting), see the [main README](../README.md) in the project root.**

## Quick start
```bash
npm install
npm run dev
```
Requires `frontend/.env` to be set up first — see the root README or
`.env.example` in this folder.
